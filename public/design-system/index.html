Logo

The Maintain Workforce lockup: the shared Maintain wordmark, the chevron mark in Hi-Vis Amber, and WORKFORCE set in Manrope. Keep clear space ≥ the cap height on all sides; minimum width 120px.

Files: assets/logo/maintain-workforce-logo-lightbg.svg (source of truth) · wordmark-on-dark.svg · wordmark-on-light.svg. Don’t stretch or add effects. The chevrons stay Hi-Vis Amber on every surface; on imagery (fourth tile) the light wordmark sits over a ~50% Ink Teal scrim so it never fights the terrain behind it.

Iconography

14 line icons at 24×24, stroke: currentColor, width 2, round caps. Use via sprite.svg; don’t mix in another set.
